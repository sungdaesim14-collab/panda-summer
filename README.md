# 판다 사부의 여름 수련 🎋

초등학생이 **스스로 정한 수련을 32일간 해내는** 여름방학 습관 앱.
"상을 받으려고"가 아니라 **하는 것 자체의 즐거움과 의지력**을 기르는 것이 목적.

> 초등학교 때 아이가 배워야 할 것은,
> ~하고자 마음먹은 일을 스스로 해낼 수 있는 의지력과 노력의 즐거움이다.

## 세 기둥

- **스스로** — 매일의 수련을 아이가 직접 고른다 (직접 입력도 가능)
- **해냄** — WOOP 작전, 양심 서약, 주간 보스로 유혹을 이긴다
- **즐거움** — 성장 마인드셋, 몰입 질문, 자기 칭찬

## 기술

- **React + Vite + TypeScript** — 화면
- **Supabase** — 데이터 (선택. 없으면 이 기기 localStorage에 저장)
- **PWA** — 홈 화면 설치 예정
- 캐릭터·카드·산 그래픽은 전부 **코드로 그린 벡터**(뿌까풍). 이미지 파일 없음

## 개발

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # 타입검사 + 빌드
```

## 구조

```
src/
  art/        캐릭터·카드·보스·산 SVG 생성기
  game/       수련·보스·카드·소리 규칙
  data/       저장소(로컬/서버) · 로그인 · PIN 해시
  screens/    화면들
  components/  카드·사부·캐릭터 조각
```
